# Fantasy 生命感人像摄影（小红书 fantasy05）吸收规则

> 来源：小红书 RedSkill 商店 fantasy05 v1.0.0，作者「FANTASY 梵想美学」。
> 蒸馏方式：完整解包阅读（SHA256 双端校验一致），**只学不装**。
> 定位：本文件管**人物状态 / 皮肤光感 / 光学效果区域 / 单人反 AI 脸 / 成组防模板化 / 参考图脱敏**——这些是普适规则，不限于 realism 路线。
> 与现有文件关系：与 candid_snapshot.md（realism 镜头层）、prompt_craft.md §11 六段式（皮肤正面）、structure_and_makeup.md §5（同妆不同脸六组差异）、engineering.md（identity_lock）互补，都写、不互相替代。

## 0. 核心心法（一句话带三个判断顺序）

> 先做人（具体状态），再做距离（亲密机位），再做构图（前景遮挡+裁切），再上光线（真实硬光），再加色彩（鲜明和谐），最后才上光学效果（克制一种）。
>
> 光学效果不是生命感本身，它只是把已经成立的瞬间推得更远。

## 1. 事件层：人物必须在做事（默认行为，禁止空白摆拍）

> 所有原创/抓拍人像默认走这条规则——除非用户明确要「极简证件式肖像」或「无表情静物人像」，否则必须给人物一个正在发生的具体事件。

### 11 类推荐状态（每张选 1 类，不要每张同一类）

- 笑到一半、刚跑过来头发还在晃、被阳光晃到眯眼
- 抓住被风吹起的布料、正在整理头发、回头时只拍到部分脸
- 手或道具突然闯入镜头、吃水果/喝水/递东西、突然笑场
- 因动作太快而局部失焦、儿童兴奋地冲向镜头
- 老人戴夸张墨镜或做幽默动作、市场摊主/街坊/游客正在完成具体事情

### 9 类禁止状态（裸摆拍）

- 标准站姿、机械微笑、空洞看镜头、纯摆拍式营业表情
- 「漂亮女孩在某地」「每张都伸手牵镜头」「每张都大笑」「每张都拿花」
- 「每张都骑车」「每张都递橙子」「每张都用风车」「每张都在花市」「每张都晒白床单」

> 与 candid_snapshot.md §1 ②③「未完成的动作 / 未完成的表情」是同一原则——后者写法更细（拆成八层装配）。本文件管**有没有事件**，candid_snapshot.md 管**怎么把事件写成镜头语言**。

## 2. 皮肤柔润哑光（与六段式互补：本文件管「不能写什么」，六段式管「写什么」）

### 高光白名单（这些地方可以出现细小破碎高光）

- 发丝边缘、眼神光点、玻璃/水滴/布料边缘、背景散景

### 高光黑名单（这些部位出现反光就是油膜脸，立刻重写）

- 额头、鼻梁、脸颊、下巴出现**大片镜面反光**——任一处出现就是翻车
- 鼻梁一整条发亮、脸颊像涂了油或玻璃釉、额头大面积反光、下巴和人中过亮
- 强侧光把皮肤打成湿亮材质（luminous skin 被误执行成油光）
- 满脸油光、塑料奶油皮、蜡像感、玉石脸、过度磨皮、HDR 皮肤、过度锐化

### 必保留的真实纹理（与六段式 §11 一致，此处再强调）

- 少量毛孔、轻微肤色差、眼下结构、嘴唇纹理、真实眉毛和睫毛根部、自然晒红、轻微雀斑或小痣、老人的皱纹和年龄痕迹

### 质感口径锁定（写进 skin 字段或提示词时直接套）

- 关键词组合：`soft matte / satin matte finish` + `naturally lit skin without specular highlights` + `subtle pore texture preserved`
- 负向词组合：`no oil-slick skin / no mirror-glare on forehead-nose-cheeks-chin / no glossy dewy skin / no porcelain wax-figure finish / no HDRI shiny surface`

## 3. 光学效果白名单区域（每张只选 1 主 + 1 辅，作用区域有边界）

| 效果 | 允许作用区域 | 禁止 |
|---|---|---|
| 焦散（caustics） | 脸侧、衣服、手臂、环境的树叶/水面/玻璃 | 覆盖全部五官 |
| 柔光与高光溢出 | 逆光发丝、白布、水花、皮肤轮廓边缘 | 整张铺雾、眼睛发糊、皮肤变奶油蜡像 |
| 色散（chromatic aberration，红青/蓝紫） | 前景物边缘、发丝轮廓、水滴、玻璃、画面外围 | 覆盖眼睛、覆盖主要五官、全图重色散、人物像故障画面 |
| 旋焦（swirly bokeh） | 脸清晰 + 背景有散景元素 + 主体背景距离足够 | 整张旋转、五官变形、建筑直线场景强行旋焦 |
| 动态模糊（甩拍/拖影） | 边缘/前景 | 脸部失锚 |

> 与 candid_snapshot.md §3「前景遮挡层」互补：前景遮挡是构图层（让画面纵深有来由），光学效果是物理层（让光在物理上不污染五官）。两者都要写，但不要混在一起描述。

## 4. 反 AI 脸最小差异（单人多版本必做）

> 多版本同角色（调同一人脸做不同表情/服装/场景）时，每张至少改变以下 9 项中的 3 项：
>
> 眼型 / 眼距 / 脸长 / 眉形 / 鼻型 / 嘴型 / 下颌 / 颧面 / 表情气质

- 允许轻微不对称、略长脸、圆脸、有颧面支撑、眼型舒展、嘴角走势不同
- 禁止同脸换衣、统一圆眼甜妹脸、统一小尖脸、完全对称、过度精致的网红模板、所有人露标准八颗牙、AI 娃娃脸、过度完美的白瓷脸、过大的玻璃眼、统一高鼻梁小嘴模板

> 与 structure_and_makeup.md §5「同妆不同脸六组差异计数（face/jaw/eyes/nose/lips/brows 每对至少 4 组不同）」互补：
> - 本文件管**单人单版本之间的差异**（同角色出多张，防止 AI 把同一张脸重复三次）
> - structure_and_makeup.md 管**多人阵容同妆的脸差**（五人阵容每个人脸都要不同）
> - 两者阈值不同（≥3 vs ≥4），用途不同，不要混用。

## 5. 成组出图防模板化（一批图 ≥5 张时强制执行）

### 景别配比（一批图默认）

| 景别 | 占比 | 关键词 |
|---|---|---|
| 近距离特写（24-35mm，脸占 1/3-1/2，可裁掉头顶肩膀，允许轻微透视变形） | 50% | 人物不一定正视镜头，镜头像进入私人距离 |
| 中近景（同时保留脸+手+正在发生的动作） | 30% | 动作必须具体，不要标准半身肖像，不要正中央站姿 |
| 特殊中景（前景大面积遮挡/低机位/仰拍/贴地/倾斜地平线/甩拍/局部出画/超近广角/非中心构图，≥1 项） | 15% | 至少满足一项 |
| 大景小人（环境本身有强形态，人物作为尺度参照） | 5% | 不能是普通景点打卡照 |

### 场景差异矩阵（每张分别定义 10 维）

每张都要分别落定：人物年龄、身份、场景、动作、道具、景别、机位、主色关系、主光学效果、情绪状态。

### 九连禁（同批不得连续重复以下组合）

- 花市+伸手、屋顶+白床单、花海+风车、小巷+自行车+橙子
- 草帽+花束遮脸、老人+夸张墨镜+水果摊、窗边白衬衫+托脸
- 大笑+直视镜头、蓝天+人物正中央

### 综合色彩主色关系（每张 = 1 主色 + 1 对比色 + 1 肤色/中性色）

12 组现成配色（蓝+橙+白 / 深绿+橙黄+肤色 / 蓝+红+暖肤色 / 黄+红+天蓝 / 青绿+粉红+暖白 / 钴蓝+橘红+银色 / 草绿+紫花+暖肤色 / 白墙+蓝天+高纯度服装色 / 雪白+红围巾+钴蓝天+玫瑰肤色 / 草绿+棕马+青蓝围巾+橘裙 / 泳池蓝+小黄鸭+白衣物+珊瑚唇 / 复古绿+钴蓝+黄铜水龙头+橙耳饰），禁止所有颜色同时抢注意力、脏黄复古滤镜、灰蒙空气、暗部发灰、赛博霓虹、低质 HDR、过度锐化、颜色溢出覆盖五官。

## 6. 参考图脱敏（视觉 DNA 提取 + 8 维至少改 5）

> 用户给参考图说「分析风格，不要抄袭」时，按本节执行。

### 视觉 DNA 只提取这些（参考图分析 → 提示词）

- 拍摄距离 / 镜头介入强度 / 光线软硬 / 色彩浓度 / 色彩关系
- 前景层次 / 裁切方式 / 动态感 / 情绪密度 / 肌肤发丝高光质感

### 禁止继承（这些不允许从参考图直接搬到新图）

- 人物身份 / 具体脸型 / 服装 / 道具 / 场景 / 动作 / 机位 / 构图骨架
- 标志性色彩组合 / 视觉叙事 / 画面记忆点

### 8 维强制差异（与参考图至少改 5 项）

1. 人物年龄或身份、2. 场景地点、3. 人物动作、4. 服装造型、5. 前景物体、6. 拍摄机位、7. 色彩组合、8. 光线方向与时间。

### 公众人物特征使用规则

- 禁止直接复刻某位明星、生成一眼可识别的公众人物脸、把多个明星平均混成一张脸、使用真人名字作为最终人物身份
- 正确方法：拆为眉眼/骨相/脸长/嘴型/表情气质/妆容与发型特征 → 随机组合为无法对应具体真人的原创人物

> 与 engineering.md 身份锁（identity_lock.locked）的关系：identity_lock 是「同角色不同场景的固定项」（脸/五官/身材/发色），本文件是「参考图到新画的强制差异项」——两者不矛盾，identity_lock 用于同角色成套组照，本文件用于参考图蒸馏新角色。

## 7. 边界与防污染

- 本文件管**人物状态 / 皮肤光感 / 光学效果区域 / 单人反 AI 脸 / 成组防模板化 / 参考图脱敏**；皮肤质感正面写法定量规则归 prompt_craft.md §11 六段式（弗曳哥）；骨相三区与妆容六要素归 structure_and_makeup.md（南鸢）；抓拍镜头层语言归 candid_snapshot.md（指北）；视频侧表演归 seedance25-prompt-skill。
