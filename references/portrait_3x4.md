# 3:4 定妆肖像规范（image-portrait-3x4 蒸馏）

> 吸收自 image-portrait-3x4 skill v1.1.1 · 2026-10-11（只学不装）。
> 用途：把角色卡变成一张**从零创造的 3:4 竖版定妆肖像**——角色定妆底图 / 面部锚点 / 脸锚点首图。
> 它不是：拿参考图重拍，也不是三视图 / 全身人物卡（那些走 `engineering.md` 与角色卡三视图渲染）。
> 在本 skill 中的位置：第 5 步生成提示词时，`portrait` 视图可按本规范组装；脸型取值优先从 `face_library_220.md` 选编号。

---

## 一、硬口径（八条，逐条不可省）

1. **比例锁定 3:4** 竖版。「锁定」只允许用于**比例**，不得用于画面边缘或构图范围。
2. **取景**：头部、全部发型与头顶，加颈项与双肩；头部与肩部充满整个画面。**用正向描述**，不做边缘声明。
3. **服饰绝对不要**：画面主体是头部、颈项与双肩的皮肤；除头饰与耳饰外不出现其他物件。
4. **背景**：标准 18% 中性灰影棚背景板 **#808080**，均匀单一色值、纯净无瑕疵。
5. **光**：默认**漫射柔光 + 平光铺照**，光线分布均匀柔和、光比极小、无硬阴影方向。
6. **身份四定值**：`[骨相]` `[五官]` `[识别]` `[气质]` **写入即固定**，生成与后续复用中都不漂移。气质属定值——**不可为了救构图去改气质词**。
7. **措辞纪律**：正向为主；**禁止裁切锁死语义**；**负向词非必要不用**，默认不含负向块。
8. **先确认后出图**：按主流程第 5.5 步，提示词经用户确认后才出图。

## 二、身份四定值：为什么气质也是定值

气质一动，眼神、眉形走向、唇形松弛度会同步漂移——而这四样正是观众认人的依据。定值化之后，「靠删气质词救构图」这条路关闭，**构图问题只能从构图句解决**。

| 字段 | 归属 | 规则 |
|---|---|---|
| `[骨相]` | 定值 ① | 从脸型库/角色卡写入，一经写入即固定 |
| `[五官]` | 定值 ② | 同上 |
| `[识别]` | 定值 ③ | 毫米级写死（痣／疤／不对称的位置与左右） |
| `[气质]` | 定值 ④ | 不可为救构图改气质词 |
| `[性别]` | 设定 · 必写 | 不写模型自猜，骨相词偏中性极易出成男性 |
| `[妆容]`（男 `[面部]`） | 设定 · 必写 | 唇色必须有具体色相；写成「淡／灰／裸」＝出男人脸 |
| `[发型]` | 设定 | 追加「含发际线、额前碎发、发丝走向与体积」 |
| `[服饰]` | ❌ 绝对不要 | 不设此维度 |
| `[姿态]` | 停用 | 肖像构图手不入画 |

## 三、措辞纪律（与 gpt-image-2 长句骨架兼容）

1. **正向为主**：把要求写成「画面是什么」，不写成「画面不能是什么」。
2. **禁止裁切锁死语义**：不声明画面边缘、不声明哪些部分不入画、不声明什么不得被切断。
3. **负向词非必要不用**：默认整份提示词不含负向块。

**禁用 → 替换对照表**：

| 禁用（裁切锁死语义） | 替换（正向描述） |
|---|---|
| 画面下缘止于锁骨线与肩线 | 肖像构图取景至肩部 |
| 锁骨以下不出现身体／胸／手臂 | 画面主体为人物头部、颈项与双肩 |
| 画面下缘切在××位置 | （删除，不做边缘声明） |
| 任何一缕发丝不得被画面边缘切断 | 完整呈现整个头部与全部发型，发型轮廓完整 |
| 裁切／出画／不入画／不得超出 | （一律删除或改正向陈述） |
| 锁定边界／锁死构图范围 | 「锁定」只允许用于比例：锁定 3:4 比例 |

**按需补极简负向块（默认不用）**——仅当出现对应现象时只补一行，用完即撤：

| 触发现象 | 只补这一行 |
|---|---|
| 出现衣物、领口、肩带 | 任何衣物、领口、肩带、布料 |
| 皮肤蜡像感／磨皮／油光 | 蜡像皮肤、塑料皮肤、油光、磨皮、美颜滤镜 |
| 出现第二个人物或倒影 | 第二个人物、重复人物、镜中倒影 |
| 出现文字、水印、道具 | 文字、水印、logo、道具 |

> 这四项之所以罕见地必要，是因为它们**无法用正向句排除**（「画面里没有衣服」本身仍会唤出衣物概念）。注意与 `realism_vs_refined.md` 的关系：refined 路线允许完美皮肤，第 2 行负向不适用。

## 四、提示词模板（中文版，可整段复制）

```
【肖像设定】一位［性别］，［年龄］，［地域与气质方向］。东方［性别］面孔。

[骨相] ［脸型、颧骨、下颌角、下巴、面部轮廓与骨点结构］
[五官] ［眼型与眼裂、双眼皮形态、眉形与眉峰、鼻梁鼻头、唇形与唇峰］
[识别] ［痣／疤／不对称，位置与左右写死到毫米］
[气质] ［神态、目光温度、眼神状态、面部张力与情绪压强］
[妆容] ［妆面名称 + 具体色相，如"极简冷妆，唇色豆沙"］
[发型] 含发际线、额前碎发、发丝走向与体积的［发型描述］
[饰品] ［头饰／发饰／耳饰的形制、材质、位置；无则写"无饰品"］

【构图与比例】竖版 3:4 比例。肖像构图取景至肩部：完整呈现整个头部与全部发型，包括头顶
与发际线；并呈现颈项与双肩。头部与肩部充满整个画面，面部中轴居中，双眼位于画面上三分之一，
平视视角，面部正面朝向镜头，目光平视镜头。

【着装】画面主体为人物头部、颈项与双肩的皮肤，肩颈自然裸露；除头饰与耳饰外，
画面中不出现任何其他物件，不出现衣物、衣领、领口、肩带、布料或披风。

【光】漫射柔光，平光铺照：光线从正面均匀铺照面部，光比极小，明暗过渡柔和，
无硬阴影方向，面部受光均匀通透，肤色还原自然，皮肤纹理清晰可见。

【背景】标准 18% 中性灰专业影棚背景板，色值 #808080，纯净无瑕疵：
均匀单一色值，无纹理、无褶皱、无渐变、无污渍、无道具、无文字。

【画风］［按用户指定或默认中式写实；菜单见 face_library_220.md 附一］

【质感】真实皮肤质感：可见毛孔、细纹与自然色差，半哑光；
中性白平衡，面部高光克制；真实商业妆容质感，非美颜滤镜效果。
```

**填空来源**：`[骨相]`~`[气质]` 从 220 脸型库按编号取气质方向、按九项字段格式生成（库随包只含索引与格式，逐条数据未随包；锚点位置自行设计写死，同批角色间查重）；`[性别]`／`[妆容]` 两行必须带上；`[发型]` 行追加「含发际线、额前碎发、发丝走向与体积」；库中的 `[镜头]`／`[姿态]` 两行**不复制**，由「构图与比例」段替换。英文版按中文段完整重译（LLM 翻译铁律，见主流程注意事项），骨架词对照：骨相 Bone structure / 五官 Features / 识别 Identifying anchors / 气质 Temperament / 妆容 Makeup / 发型 Hair / 构图 Composition and aspect ratio / 着装 Attire / 光 Light / 背景 Background / 画风 Style / 质感 Texture。

## 五、工艺基线：凭什么判一张脸合格

**六条优先级（冲突时自上而下）**：

```
角色准确 > 漂亮
真实     > 完美
辨识度   > 模板脸
人物感   > AI 感
商业完成度 > 炫技
原创身份 > 像某个真人
```

在 3:4 定妆肖像上收敛为一条裁决链：

```
身份四定值 > 比例与取景 > 无服饰 > 皮肤干净但不磨皮 > 光与背景纯净度 > 商业完成度
```

**Clean Cinematic 总则（可背）**：人物可以粗粝，摄影必须干净；环境可以昏暗，脸必须清楚；皮肤可以不完美，但不能显脏；去掉网红感，不等于去掉高级完成度。

**中性白平衡与低高光**：额头、鼻梁、颧骨、上唇不得出现白色高光块；环境色不得把脸染成黄／橙／铜／金。

**参考距离分级**：Level 1 = 同一角色的新变体（四定值不得替换）；Level 2 = 同类型换另一个人（至少替换 3 个面部字段 + 1 个身份锚点，再新增 2–3 个记忆点）；Level 3 = 只借情绪与氛围。**定妆肖像一旦确认即 Level 1**——需换人另起一次创造，不在同一份设定上改字段。

## 六、资产产物链（三级产物，2026-10-11 王老师口径）

角色最终出图产物为三级：**肖像 → 肖像三视图 → 全身三视图（无头部）**。

**参考板层级（Face-First，character-continuity-bible 蒸馏，2026-10-11 补）**：若项目需要把角色资产**合成一张参考板**（角色设定板/参考图集），身份效用高于氛围——**大而清晰的大脸特写做主导面板，约占画面 40–55%**，光线保持中性或柔和建模光，骨相/眼型/眼睑/鼻/唇/下颌/发际线/皮肤纹理/年龄感/不对称全部可读；**不要**把主区域花在环境氛围英雄图上。层级顺序：

```text
大脸身份特写（主导，40–55%）
→ 正/背全身比例与服装视图
→ 表情或侧脸证据
→ 道具/配饰细节
→ 小动作剪影（有用时）
```

氛围可以统一色调与情绪，但**不得隐藏、缩小、逆光或风格化掉身份参考**；确需氛围英雄图，另起一张独立资产。本 skill 默认走三级分离产物（下），Face-First 层级仅在用户要单张合成板时启用。

**为什么全身三视图去掉头部**：头部身份已由前两级锁定（肖像定气质与脸，肖像三视图定多角度骨相）；全身图再画一遍头，等于引入第二份头部描述——漂移与画崩风险翻倍，且返修时头部问题会牵连身体重跑。头部资产与身体资产**分离管理**，各自可验收面更小、返修互不牵连。

### 6.1 第一级：肖像（3:4 定妆）

见本文件 §四 模板。回答「这条路线对不对」：气质、脸、识别锚点。

### 6.2 第二级：肖像三视图（头部资产锁定）

```text
【产物】肖像三视图设定板：16:9 横版，一行三格，等高、间距均匀。
从左到右为：正面肖像、四分之三侧肖像、正侧肖像。取景至肩部（同定妆肖像口径），
头部完整，发型轮廓完整。三格为同一个人：骨相、五官、识别锚点、发型在三个视角
完全一致，痣/疤/不对称的位置与左右在三格中一致呈现。背景、光、画风与定妆肖像
一致（默认 #808080 中性灰 + 漫射柔光）。
```

英文骨架：

```text
Head three-view model sheet: 16:9, one row of three equal panels — front, three-quarter,
and profile head portraits, framed to the shoulders, whole head and hairstyle fully shown.
All three panels show the same person: identical bone structure, features, identifying
anchors (moles/scars/asymmetry with exact position and side), and hairstyle across views.
Background, lighting and style consistent with the confirmed portrait.
```

回答「这个头部能不能复用」：多角度骨相 + 锚点一致性。生成方式：以已确认肖像做图生图参考（脸锚点铁律）。

### 6.3 第三级：全身三视图（无头部，身体资产锁定）

```text
【产物】全身三视图设定板（无头部）：16:9 横版，一行三格，等高、间距均匀。
从左到右为：正面全身、四分之三侧全身、正侧全身。头部、头发和面部不可见，
由空白背景遮挡，仿佛拍摄时完全没有头部。姿态放松，双臂自然垂于身体两侧，
完整入镜不裁切。本视图只回答：头身比、肩宽、体态、四肢比例、服装结构
与配饰位置。背景纯浅灰，均匀柔光，无道具、无环境元素。三个视角为同一身体：
比例、服装、配饰完全一致。
```

英文骨架：

```text
Full-body three-view model sheet (headless): 16:9, one row of three equal panels —
front, three-quarter, and side full-body views. The head, hair and face are not
visible, occluded by the empty background, as if the figure had no head at all when
photographed. Relaxed posture, arms hanging naturally at the sides, fully framed
without cropping. This sheet answers only: head-to-body ratio, shoulder width, build,
limb proportions, garment structure and accessory placement. Plain light-gray
background, even soft light, no props, no environment elements. All three views show
the same body: identical proportions, garments and accessories.
```

**验收要点**：三格头部遮挡方式一致（颈部以上均为空白背景，无头模、无残影）；头身比与角色卡 `body` 字段一致（走 `validate_card` 比例审核）；服装结构与 `identity_lock.locked` 一致；双臂自然垂于身体两侧，无手部崩坏。

> 出片阶段（Seedance 等）使用时：**肖像三视图管头部，全身三视图管身体**，与肖像一起按需组合喂参考图——替代原「全身四视图单卡」的用法（见 §七 三步法第 2 步注）。

## 七、Seedance 2.5 跨场景保脸三步法（视频侧延伸）

先记两个技术事实：
- **锁种子不能跨场景保脸**。种子编码整张图的噪声模式；换场景整个噪声模式被重新解释，脸跟着变。种子只适合同场景精修。
- **Seedance 2.5 靠参考图，不靠文字**。写再多形容词不如喂一张对的参考图。

**三步，顺序不能反**：

1. **出定妆图**：本规范 3:4 肖像，回答「这条路线对不对」。
2. **拿定妆图出四视图**：正面／四分之三侧／正侧／背面，纯色背景、均匀光、站姿一致。给模型一张正面头像却要求转身，它必须自己发明没见过的半边脸——那正是漂移出现的地方。（四视图提示词骨架见 `engineering.md` §7）
   > **注（2026-10-11 王老师口径）**：四视图按本文件 §六 三级产物链替换为「**肖像三视图（头部）+ 全身三视图（无头部）**」两级组合——头部与身体分离锁定，出片时按需组合喂参考。原「正/侧/背全身四视图单卡」仅作背景理解，不再作为产物输出。
3. **正片阶段用一行锚定句（约 60 字），每集复制不改，只改场景和动作**：

```
25 岁女剑修，鹅蛋脸偏长、单眼皮细长眼、瞳色深褐，
右眼下 2mm 泪痣、左眉尾浅旧痕；
黑发低束成髻，素白长袍配灰青布带，长剑背左后。
```

喂 Seedance 2.5 时**定妆图和四视图两张一起当角色参考**：一张管气质与脸，一张管结构与比例。

**两个限制**：参考图固定的是身份不是行为——参考强度调高角色锁得死但不听提示词，调低则相反，每张图自己找平衡点；某一格总崩说明第一张定妆图里对应结构没说死，回去补定妆图，别反复抽卡。

## 八、出口前合规三件事

1. **别用市面通用模板**。爆款脸提示词被几百个团队在用，撞脸风险最高。220 库每张脸带独有锚点，是给「一人一剧」用的。
2. **平台在查跨剧撞脸**。红果短剧已上线 AI 人脸相似度比对，据行业解读**跨剧角色面部相似度超 65% 会被直接驳回**（行业解读口径，非官方文档，未溯源，谨慎引用）；抖音有预检工具；微博对同质化 AI 内容扣减广告分成。**要做的是每个角色一张新脸，而不是每集换一张脸**。
3. **留一点不完美**。AI 脸让人不适不是因为丑，是因为太标准，标准到大脑防伪机制报警。毛孔、轻微肤色不均、一道淡细纹、一颗位置精确的痣——「不完美」是「活人感」的藏身处。

## 九、QA 九条（出图后逐条核验）

1. 竖版 3:4；2. 头部/发型/头顶/发际线完整；3. 取景至肩、面部中轴居中、双眼约在画面上三分之一；4. 除头饰耳饰外无任何物件；5. 背景 #808080 单一色值；6. 四定值与设定一致无漂移；7. 妆容唇色有色相、发色发际线一致；8. 饰品形制位置材质一致；9. 光均匀柔和小光比、皮肤半哑光可见毛孔、中性白平衡。

任一条不过即重出，不做「看起来差不多」的妥协。

## 十、边界与防污染

- **本规范管「定妆肖像」一种产物**：3:4、无服饰、灰底、平光。角色卡三视图 / 全身视图仍走 `generate.py` 主管线，两套模板不混写。
- **`[气质]` 定值 vs 南鸢「气质与结构解耦」不冲突**：南鸢说的是**设计阶段**气质不强制决定骨相；本规范说的是**出图阶段**气质词写入后不得为救构图而改。一个管入口，一个管出口。
- **措辞纪律（正向、无裁切锁死）适用于本规范的构图段**；gpt-image-2 主管线的负向对抗词体系（去底模脸五连）不受影响，各走各的。
