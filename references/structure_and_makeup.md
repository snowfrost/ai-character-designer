# 骨相结构与妆容规则（南鸢 nuyoah「人像角色设定师」蒸馏）

> 来源：GitHub `nuyoah-ai-works/nuyoah-portrait-character-designer` v0.2.1（南鸢 2026-09-11 公众号《想要什么气质，直接说：我的人像角色设定 Skill 公开了》），2026-09-12 吸收，**只学不装**。与麦橘骨皮形神互补：麦橘「骨」单字定方向（敦/修），本文件负责把方向落成**具体结构关系句**；与弗曳哥六段式（prompt_craft.md §11）互补：六段式管皮肤质感，本文件管骨骼结构与妆容。

## 1. 骨相三区关系写作法（原创人物必做）

「骨相清晰」「立体高级」是无效大词——模型补全空间太大。每次原创人物默认写出**至少三个区域的具体关系**（用户没点名骨相也做；极简/固定脸/局部任务服从用户范围）：

- **额头与眉眼区**：额头前后倾向、眉骨起伏、眼窝深浅。组合示例：「眉骨起伏平缓、眼窝较浅，眉眼之间留有舒展空间」
- **颧部区**：横向宽度、高低位置、向前突出程度**三项独立**，写清与太阳穴/面颊的过渡。「颧部位置略高，横向宽度适中，饱满面颊柔和包覆颧骨」
- **下颌/下巴区**：相对颧宽、下颌转折、下巴长短/圆方尖/前后。「下颌比颧部略窄，转折圆缓，下巴短圆且不后缩」

**柔和的脸也有结构**：平缓眉骨、浅眼窝、圆缓下颌是明确的设计选择，不是没写骨相。不给所有人深眼窝、高颧骨、锐下颌。

**轴分离清单**（写混了就等于没写，审核时逐条对照）：

| 错误合并 | 正确拆分 |
|---|---|
| 眉骨 = 眉毛 | 眉骨起伏是骨骼；眉毛浓淡/弧度是毛发，分两个字段 |
| 眼窝深 = 双眼皮褶皱 | 眼窝是骨骼凹陷；褶皱是眼睑，深色眼影不自动判眼窝深 |
| 颧位高 = 脸宽 | 位置高低与横向宽度独立；高颧不捆绑宽脸 |
| 骨点突出 = 面颊消瘦 | 骨骼突出与软组织饱满度独立，可共存 |
| 中庭长 = 面中前突 | 纵向比例 ≠ 前后凸凹；高鼻梁不自动代表面中前突 |
| 尖下巴 = 下巴前伸 | 形状与前后关系独立；短 ≠ 后缩 |

## 2. 气质与结构解耦（对麦橘16型的边界修正）

> ⚠️ 与 SKILL.md 16 格速查表的关系：16 型（皮×神定阵营、骨×形定细格）是**起点候选**，不是脸型模板。用户锁定结构或明说「这张脸我喜欢」时，气质改从妆、表情、造型路径实现，不强行改骨相。

- **一种气质可以有不同的脸**：圆脸可以清冷，单眼皮可以甜美，长脸可以温柔——这些是可共现组合，不是禁配
- **主气质决定整体视觉关系，不强制决定骨相**。实现路径四选一为主、一为辅：①结构强化 ②妆容强化 ③表演强化 ④反差组合。避免所有部位同时拉满
- 例：「英气为主、柔和为辅」= 较明确下颌+平直眉（结构），再放松眉间+柔边唇妆（妆容）保留亲和；**也完全可以保留圆脸，以眼神与造型表达英气**
- 多个气质无优先顺序时，按完整句意选一个主导方向并显式说明，其余气质走表情/妆/造型做层次
- 国籍/城市/文化语境不直接导出脸型、眼鼻形态或肤色；肤色由独立要求或创作方案决定

## 3. 妆容六要素控制

先定**视觉目标**（强化轮廓 / 保留圆润 / 增加上提方向 / 柔化锐感 / 制造反差），再落笔。每个关键妆容控制写齐六要素（不必都是长句）：

> **部位 + 颜色 + 落点/范围 + 线条/方向 + 质地/边缘 + 强度**

- 例：「透明的暖粉色腮红，轻轻晕染在双颊中央，边缘柔和」= 部位(腮红) + 颜色(透明暖粉) + 落点(双颊中央) + 质地边缘(柔边)
- **默认一个重点**：眼 / 唇 / 双颊 / 整体自然，四选一为主，其它配合（舞台妆/实验妆除外）
- **色彩具体化**：「奶茶」「豆沙」「吃土」等流行色名要补灰棕、粉棕等实际色相与相对饱和度
- **质地三分离**：基础肤色 / 薄透程度（覆盖度）/ 表面反光是三个独立轴——「清透」≠「冷白」，「水光」≠全脸油亮，全脸不同时叠互相排斥质地（全脸柔雾+局部湿亮唇可以，指向不同部位）
- 底妆不为人人添加油脂、干燥纹理、斑点来「求真实感」——真实感是六段式的事（prompt_craft.md §11），底妆只管覆盖与反光

**条件适配精选**（结构→妆的候选，不是禁令表）：

| 已知结构 | 目标 | 做法 | 不许越界 |
|---|---|---|---|
| 圆轮廓 | 保留自然气色 | 双颊中央柔边晕染，可横向展开 | 圆脸可横向腮红，无禁令 |
| 圆轮廓 | 增加上提方向 | 腮红从外侧颧部向太阳穴轻延 | 不把脸改窄 |
| 天然上扬眼角 | 柔化锐感 | 短、平细眼线 | 自然眼角仍上扬 |
| 天然下垂眼角 | 增加上提 | 外眼线轻微提起 | 不是把眼角改成上扬眼 |
| 轮廓明显 | 降攻击性 | 眉头与唇缘柔化 | 骨骼保留 |
| 柔和轮廓 | 增利落感 | 清晰眉尾或唇缘**选一个**重点 | 不自动加高眉骨削下巴 |
| 自然薄唇 | 更饱满妆效 | 轻微外扩描唇/局部光泽，并说明是妆面 | 原生唇形记录不变 |

## 4. 点名式修改协议（承接 identity_lock 字段）

用户点名「这部分留下」时，改的是**自由轴**，锁定项一个字不动：

- 「这张脸我喜欢，别动，只把妆改一下」→ 锁定全部面部结构 + 肤色 + 发型 + 拍摄设定，只重写妆容段
- **局部修改不扩散**：「只换口红颜色」= 保留唇形、唇缘、光泽、其它妆容和拍摄，只换色相
- 「柔和一点」= 减少当前**主导线条**的锐度/强度（先从眼线锐度、眉头、唇缘调），不同时改脸型、肤色、发型
- 角色卡 `identity_lock.locked` 列什么就锁什么；原稿未说明的深度保持未说明，**不趁机补全**（如原稿没写眼窝深浅，改妆后也不新增）
- 修改后交付**完整新稿**，不能写「其它同上」

## 5. 同妆不同脸（阵容差异程序）

做多人阵容（同妆不同脸）时的专用流程：

1. **先写共享妆容句**：固定底妆质地、眼影色彩与铺色逻辑、眼线粗细与方向、睫毛状态、腮红色彩与相对落点、唇色与质地/边缘——**每个人的 Prompt 原样复用这段**，句后只可补必要的面积适配（「按脸适配」只调整覆盖面积和相对坐标，不替换落点逻辑/线条方向/质地）
2. 反例警示：同一套桃粉妆，第二人不能改成斜扫腮红+丝绒唇、第三人改成果冻唇——这些是**不同妆**
3. **六组差异计数**：face（整体长宽+纵向比例）/ jaw（颧颌宽度关系+下颌转折+下巴）/ eyes（眼形+开合+间距+眼睑）/ nose（高度+宽度+鼻尖）/ lips（宽度+上下唇比例）/ brows（自然眉形+眉眼距）。**每对人物至少四组不同，其中 face/eyes/nose 至少两组**
4. **换发型、换衣服、换肤色、加痣、加雀斑不算结构差异**，不能拿来凑数
5. 采样顺序：先满足兼容和锁定 → 拉开阵容差异（优先替换未锁定的整体比例/眼部/鼻部组）→ 再考虑次要装饰；最多两轮局部修复
6. **反模板检查**：无意识重复「窄小脸 + 较大杏眼 + 高细鼻梁 + 尖下巴 + 饱满小嘴」组合，出现 ≥3 个触发复核——用户明确选择时保留（在自由轴建差异）；只是默认补全且阵容内重复时，替换两个未锁定主要结构组。**单人不必为躲模板强行制造怪异瑕疵**

## 6. 冲突矩阵精选（写卡/改卡前自查）

| 情况 | 类型 | 处理 |
|---|---|---|
| 同轴同状态同时「窄」又「宽」 | 硬冲突 | 保留最近明确要求；判不了就问 |
| 锁定圆钝下巴，候选改尖下巴 | 锁定违反 | 回候选恢复锁定项 |
| 下颌比颧宽却写「颧部为全脸最宽」 | 空间冲突 | 明确比较范围，修正一条 |
| 圆脸+清冷 / 单眼皮+甜美 / 长脸+温柔 | 可共现 | 用妆、表情、造型实现 |
| 中庭长+下庭短 / 高鼻背+宽鼻翼 / 大眼+宽眼距 | 可共现 | 不同轴，不误判矛盾 |
| 天然下垂眼角+上挑眼线 | 表现层差异 | 天然眼角和画出的线**分开写**，各标各的 |
| 柔雾皮肤+局部湿亮唇 | 可共现 | 指向不同部位 |
| 同一唇面同区域全哑光+镜面 | 硬冲突 | 选一项或分区 |

## 7. 参考图纪律

- 参考信息分三级：**可见 / 推测 / 不可确认**。强光影下的深眼窝、清晰颧部 → 标「推测」，不当确定骨骼事实；眼睛闭合或被刘海遮住 → 完整眼型/眼距不可确认，只写可见部分
- **只拆妆不带走脸**：借参考图的妆容时，明确「不要把参考人物的脸带过去」，妆容应用到自己的人物上，保留她原来的五官和肤色
- 妆容复刻效果取决于生图模型对妆容描述的消化程度，不归咎于结构描述

## 边界

- 本文件管**脸部骨骼结构、妆容、修改协议、阵容差异**；皮肤质感归六段式（prompt_craft.md §11）；写实 vs 精致路线归 realism_vs_refined.md；视频侧表演归 seedance25-prompt-skill
- 阈值（四组差异、六要素）是设计治理启发式，不保证图像辨识度——出图后按「同妆换脸先看脸再看妆；同脸换妆先看身份再看局部」审查
- 骨相三区与六段式皮肤是**两套独立语言**：三区写骨骼关系，六段写皮肤表面——都写，不互相替代

## 自测 prompt

> 用户说「设计一个清冷的圆脸女孩，妆容只保留腮红重点」。请按本文件输出：① 骨相三区至少两套不同候选（清冷不强求改脸）；② 腮红六要素句（含落点/边缘/质地）；③ 如果圆脸+清冷被你判为矛盾，指出错在哪；④ 用户接着说「脸不动，只把腮红换成冷粉」——列出锁定项和自由轴。
