# §12 抓拍感公式（GitHub指北开源抓拍 Skill 蒸馏）

> 来源：公众号「GitHub指北」《开源抓拍 Skill，你也可以是 AI 摄影师》（2026-09-06），
> 原始 skill 本体未公开（需公众号私信获取），本文从正文三组示例提示词逆向蒸馏。
> **定位**：realism 路线「生活随拍型」的**进阶镜头层语言**——比"手机随手拍"更有摄影设计感，
> 核心是**街拍 / 纪实抓拍（candid snapshot）**质感，适合同角色成套生活组照。

## 0. 核心心法

**抓拍感 = 设计好的偶然。**
所有看起来"随机"的元素（前景入镜、失焦、倾斜、没看镜头、未完成的动作）都必须**显式写出来**。
模型不会自己产生偶然感，你写了它才有；你不写，它就默认给一张摆拍的影棚图。

与既有知识的关系：
- 骨相三区（南鸢）写**脸**、六段式皮肤（弗曳哥）写**皮肤表面**、抓拍公式写**镜头与场景**——三层独立语言，都写、不互相替代；
- 归入 realism「生活随拍」子类型时，抓拍公式的镜头/场景块**替换**原收尾模板中较弱的"手机快照"泛词，负面词体系不变。

## 1. 八层装配公式

按顺序装配，每一层都是提示词里独立的一句话：

| 层 | 写什么 | 要点 |
|---|---|---|
| ① 人物设定句 | 「一个极具镜头感的 + 身份 + 皮相 + 服装风格」 | 服装写风格名 + 细节面料（蕾丝甜酷 / 韩系轻熟 / 清冷文艺），不写具体单品清单 |
| ② 正在进行的动作 | **未完成的动作**（正从冰柜拿饮料 / 刚准备起身 / 低头整理裙摆） | 动作必须"进行中"，摆好姿势就是摆拍 |
| ③ 未完成的表情 | 欲言又止 / 刚睡醒的慵懒感微微抿嘴发呆 / 低头没注意周围 | 配合动作形成"被打断的一瞬" |
| ④ 焦段与机位 | 见 §2 词库，焦段 + 机位 + 拍摄视角一句话 | 24mm 畸变张力、35mm 纪实、50mm 自然透视、85mm 压缩（抓拍少用） |
| ⑤ 构图设计 | Dutch Angle 倾斜 / 人物放画面极侧边大面积留白 / 几何线条切割画面 | 楼梯扶手、窗框、货架等场景几何都可当切割线 |
| ⑥ 前景遮挡层 | **虚化的前景物自然侵入画面**，部分遮挡人物 | 全篇抓拍感的最强一招，见 §3 |
| ⑦ 光线驱动 | 环境光源打在人物身上 + 明暗交界 | 冷柜冷光 / 玻璃反射光打亮半边脸 / 顶部自然光，人物处在明暗交界 |
| ⑧ 色彩纪律 | **最多三个色块** | 冷灰+白+微弱绿 / 白+翠绿+肤色 / 暖灰+米白+肤色，写死三种颜色 |
| ⑨ 失控感收尾 | 局部失焦、轻微运动模糊、噪点/颗粒、广角畸变 + 质感锚句（§4）+ 无意识声明 | 收尾必须有质感锚句，否则退回摆拍 |

## 2. 焦段机位库

| 焦段 | 透视语言 | 常配机位 |
|---|---|---|
| 24mm 超广角 | 近距离畸变张力、环境占比大 | 贴地低机位仰拍 |
| 28mm | 广角纪实，畸变比 24 收敛 | 极低机位、边走边拍 |
| 35mm | 纪实人文标准焦段 | 平视、跟随视角 |
| 50mm | 自然透视，接近人眼 | 平视抓拍、高处俯拍 |

## 3. 前景遮挡层词库（最强一招）

虚化/半遮挡的前景物制造"偷拍视角"和画面纵深感：

- 冰柜玻璃门边缘 + 虚化的货架（玻璃反射与真人重叠形成**叠影**）
- 虚化的白色窗帘一角，自然侵入画面**遮住一侧肩线**
- 楼梯扶手栏杆**从前景缝隙中拍过去，局部遮挡她的脸部边缘**
- 通用：门框边缘、公交站台立柱、花束一角、伞沿、路人肩膀（虚化）

写法要点：前景物要**有来由**（来自场景本身），遮挡要**不完整**（边缘/肩线/脸缘），
并写明"自然侵入画面"。

## 4. 失控感词库与质感锚句

**失控感**（每张选 2–3 个，不叠加过多）：
局部失焦 / 轻微运动模糊 / 近距离广角畸变 / 轻微数码噪点 / 自然颗粒 / 浅景深

**质感锚句**（收尾定调，每张选一句）：
- CCD 直闪的即时快照质感，像一张偶然被朋友拍下的生活瞬间
- 便携式相机即时感
- 摄影师边走边拍的观察视角，不经意的真实瞬间
- 人物完全没有意识到镜头（**无意识声明**，建议常驻）

## 5. 原文三组示例（保留原话，作范式参照）

1. 「一个极具镜头感的韩国 INS 网红，皮肤白皙，傲人身材，穿着蕾丝面料的甜酷私服，正从便利店冰柜里拿出一瓶饮料，欲言又止的表情。24mm 超广角近距离，贴地低机位仰拍，便利店的冷白灯光和冰柜冷光打在她身上，前景是冰柜玻璃门边缘和虚化的货架，玻璃反射与真人重叠形成叠影。倾斜的 Dutch Angle 构图，冷灰 + 白 + 微弱绿色的克制色彩，近距离广角畸变，局部失焦，CCD 直闪的即时快拍质感，像一张偶然被朋友拍下的生活瞬间。」

2. 「……胸像近景。她靠在现代玻璃花房的窗边，刚刚醒来的慵懒感，微微抿嘴，发呆到没有注意周围。50mm 自然透视，平视抓拍，玻璃建筑的反射光打亮她半边脸，前景是虚化的白色窗帘一角，自然侵入画面遮住她一侧肩线。人物放在画面极侧边，大面积留白，穿过玻璃的细碎光影落在锁骨上，白 + 翠绿 + 肤色三个色块。浅景深，局部失焦，自然抓拍，人物完全没有意识到镜头，轻微数码噪点，便携式相机即时感。」

3. 「……低头整理裙摆，刚准备从老公寓楼梯间的台阶上起身。50mm 自然透视，从楼梯上方向下俯拍，画面被楼梯扶手的几何线条切割，扶手栏杆从前景缝隙中拍过去，局部遮挡她的脸部边缘。楼梯间顶部洒下自然光，人物处在明暗交界，暖灰 + 米白 + 肤色，最多三个色块。轻微运动模糊，摄影师边走边拍的观察视角，便携式相机即时感，自然颗粒，不经意的真实瞬间。」

## 6. 批量组照模式（原 skill 的用法，可吸收进对话流程）

用户可下组合指令批量生成 N 组，维度自由组合：
- 指定场景：「生成十组，全部使用荷塘场景」
- 指定服装：「生成五组，全部 BM 风」
- 指定画幅：「生成十组，9:16」
- 组合指定：「生成五组，荷塘 + 小香风 + 28mm + 极低机位」

→ 同角色批量组照仍走**脸锚点图生图**铁律（SKILL.md 注意事项），抓拍公式只改
镜头/场景/服装/构图块，人脸身份块完整重写不变。

## 7. 边界与防污染

- 本公式是**镜头与场景层**语言，全部走 gpt-image-2 自然语言长句，不引入 SD/Lora 语法；
- 只用于 realism 路线（生活随拍子类型为主，棚拍电影感子类型可借用前景遮挡与三色块纪律，
  但不用 CCD 直闪/便携相机锚句）；refined 写真路线不用"失控感"词；
- 「极具镜头感」与「人物完全没有意识到镜头」并不矛盾：前者夸的是长相上镜，后者写的是拍摄瞬间状态，两个词都要保留。
