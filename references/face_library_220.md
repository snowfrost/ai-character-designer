## 一、问题定义：「千篇一律」是三层收敛的必然结果

连着看三部 AI 漫剧，男主角像同一个人换了几套衣服——女的一律瓜子脸大眼睛翘鼻子，男的一律长尖脸高眉骨薄唇，判谁是谁只能靠服化道。把提示词从「清秀」改到「温婉」再改到「明艳」，出来的仍是那几张脸。

原因不在"美看多了"，在同一种美看多了。收敛分三层：

| 层 | 收敛来源 | 机制 |
|---|---|---|
| 第一层：模型里 | 训练数据偏向端正高吸引力的面孔；投放方又倾向挑符合主流审美的结果 | 两方叠加 → 模型默认输出一张"审美平均值"，五官被抹平到最不出错的位置 |
| 第二层：提示词里 | 写「一个好看的美女」等于什么都没指定 | 模型没有创作方向，只能复用内置模板。**笼统词不是"要求宽松"，是"放弃指挥权"** |
| 第三层：创作者手里（最反直觉） | 「对称／无瑕／标准／没有一处不协调」 | 这些词指向的不是"好看"，是"平均"——而**平均只有一张脸**。越是要求完美，越是要求趋同 |

**破解方向一句话：把变量从形容词挪到骨相和瑕疵上。**
「气质清冷」四个字模型听不懂；「下颌线清瘦利落 + 右眼下 2mm 一颗痣 + 唇色豆沙偏灰」它听得懂。

## 二、这套脸型库是一套取样机制，不是口号

把"美"想成一个坐标系：

- **横轴 = 骨相**：脸型 × 颧骨外扩程度 × 下颌角形态
- **纵轴 = 气质**：冷／暖 × 锐／钝（决定眼神、眉形、唇形走向）
- **第三维 = 识别锚点**：痣／疤／不对称，位置必须写死到毫米级

同一个坐标系里，只要骨相与识别锚点不同，就算都"美"，也是不同的美。

**三个动作，顺序不能反：**

1. **先定骨相 → 再定五官 → 最后定气质。** 反过来做（先"我要一个清冷的角色"再往下推五官）必然收敛，因为"清冷"在模型里只对应一套五官组合。
2. **每张脸必须带一个识别锚点**：一颗位置精确的痣、一道贯穿眉骨的疤、一个单边耳饰。**锚点比任何宏观形容词都更能锁住身份**；画风波动时只要锚点还在，观众就能认出来。
3. **主动留"可控瑕疵"**：自然毛孔、轻微肤色不均、淡细纹、轻微五官不对称。**完美等于虚假，参差才是真人**——既是防审美疲劳的关键，也是防"恐怖谷"的关键（太标准的脸会触发大脑的防伪报警）。

## 四、九项格式与六条铁律

### 九项字段

```
[性别]  先锁性别：不写这一行模型自己猜，而「骨感清冷」这类描述十有八九被猜成男性
[妆容]  女性用（男性为 [面部]）：唇色必须有颜色，「唇色淡」在画面上就是没血色，直接往男性化走
[骨相]  脸型、颧骨、下颌角、下巴 —— 决定「长得不一样」
[五官]  眼型、眉形、鼻、唇形 —— 决定「美得不一样」
[发型]  按年龄与气质配，不写会被默认为「黑长发散发 + 深色长袍」这类通用古装件
[识别]  痣、疤、不对称，位置写死到毫米和左右 —— 决定「观众能不能记住」
[气质]  给这个角色一个性格底色
[镜头]  正面半身 + 面部朝向镜头 + 目光方向 —— 决定「脸朝哪边」
[姿态]  上身姿势 + 双手去向 —— 决定「手放哪里」
```

### 六条铁律

1. **`[性别]` 不能删。** 库里的骨相描述（窄长菱形脸、颧骨外扩、薄唇）单独看没有性别指向，去掉这行模型默认往男性走。
2. **`[妆容]`／`[面部]` 不能删。** 对女性尤其关键：唇色一旦写成「淡／灰／裸」，出来就是男人脸。库里唇色全部带具体色相（赤茶、暗玫瑰、豆沙、浅玫），**不是修辞，是防性别漂移**。
3. **`[镜头]` 不能删，也不能只写「半身像」。** 不写朝向，模型会自己挑"最有氛围"的角度，结果往往是**回眸侧脸**；「疏离」「有压迫感」这类气质词会把它进一步推向侧目。默认值已写死「面部朝向镜头」，要正脸就别动它。
4. **`[姿态]` 不能删，尤其不能漏掉「双手」的去向。** 半身构图里手必然入镜，不规定位置模型会自己安排，最常见的安排是**托腮、扶脸、撩头发**——一张角色设定图就变成了姿势写真。默认已写死「不触碰面部／双手不入画」，别删。
5. **`[识别]` 一个字都别动。** 那是这张脸的身份证，也是唯一能让观众在几十集后认出它的东西。
6. **`[画风]` 和 `[光]` 不写在条目里**，从菜单按需取。刻意设计：把风格层抽出来，同一张脸才能走 16 种画风、8 种光型，而不是一身造型用到底。

### 操作要点

- **整段复制，从 `[性别]` 那一行开始**，别只复制 `[骨相]`。
- 骨架排列顺序：**第 1 条写 `[性别]`，第 3 条写 `[镜头]`，第 4 条写 `[姿态]`** —— 这三行分别防「女脸变男」「正脸变侧脸」「手乱放」。
- 男性别删 `[镜头]` 行，否则容易出一张「侧脸耍帅」、看不清正脸结构；男性的性别漂移方向相反（被画成女相），靠 `[面部]` 行里的眉形、胡茬与下颌青影锚定。

## 五、风格层 / 身份层分离（本库最核心的设计）

`[画风]` 行是个开关。20 张脸全写「中式写实」的副作用是：**只用这一套跑，20 张脸就是同一种画风**——不是模型不行，是风格层被写死了。

```
[骨相] ...   ← 身份层，不动
[五官] ...   ← 身份层，不动
[识别] ...   ← 身份层，绝对不动
[气质] ...   ← 半固定，可小幅调
[光]   ...   ← 随风格走
[画风] ...   ← 这一行就是开关
```

**角色一致性与风格多样不矛盾，因为它们是两层**：身份层负责「是同一个人」，风格层负责「不是同一张图」。把两层混在一起写，两头都做不好。

> **前四项才是正脸，后四项是分镜角度。** 做角色设定图、定妆图、以及一切要拿去做一致性锚点的图，**必须用前四项**；后四项只用于正片里需要氛围的镜头，用它当锚点会让后续所有图都认不出正脸。
>
> **出图仍是侧脸的补救顺序**：① 把 `[镜头]` 行**提到提示词最前面**（位置越靠前权重越高）② 在 `[气质]` 里把「目光有压迫感／疏离感」这类词删掉或换成「目光平静直视镜头」③ 负面词里加「侧脸、回眸、背对镜头、只露半边脸」。


> **前三种最通用。** 做角色设定图与定妆图建议用第 1 或第 2 种，**手不入画或手放身侧，就不会有手部崩坏的风险**。
>
> **手部控制的三道保险**：① `[姿态]` 写明双手去向 ② `[镜头]` 里可加「裁切于胸口以上」（胸像构图手根本不入镜）③ 负面词加「托腮、扶脸、摸头发、手托下巴、手挡脸、多指、六指、手指畸形」。

### 换风格守三条

1. **只换风格层，不动身份层。** 一旦顺手把「窄双眼皮」改成「丹凤眼」，那是换脸，不是换风格。
2. **跨度大的风格，分两轮走。** 小跨度（写实 → 三渲二／赛璐璐）直接上参考图就能成；大跨度（写实 → 水墨／Q 版／剪纸）要先用文字把风格出对、**脸允许漂一点，再把脸拽回来**。原因是参考强度是个旋钮：调高，角色锁得死但不再听风格词；调低，风格生效但脸会松——大跨度里这两件事没法同时满足。
3. **变完之后，先看小痣还在不在。** 那是最容易丢的一项，也是观众认人的第一依据。**画风可以换，痣不能丢。**

## 六、让 Seedance 2.5 记住这张脸：靠的不是提示词

先记两个技术事实，能省掉很多次无效调参：

- **锁种子的做法不能跨场景保脸。** 种子编码的是整张图的噪声模式，不只是角色的脸；把场景从室内换到雪地，整个噪声模式被重新解释，脸也跟着变。**种子只适合在同一个场景里做精修，不适合跨场景。**
- **Seedance 2.5 靠的是参考图，不是文字。** 写再多形容词也不如喂一张对的参考图。

### 三步，顺序不能反

**第一步：出定妆图。** 用上面的九项提示词块 + GPT Image 2.5，把脸和气质定下来，带场景、带光、有情绪。**这张图回答的是「这条路线对不对」。**

**第二步：拿定妆图出四视图。** 正面、四分之三侧、正侧、背面，四个全身像并排，纯色背景、均匀光、站姿一致。**这张图回答的是「这个角色能不能复用」。**
> **注（2026-10-11 王老师口径）**：产物层面四视图替换为「肖像三视图（头部）+ 全身三视图（无头部）」两级组合，详见 `portrait_3x4.md` §六；下述四视图骨架保留作生成方法参考。
之所以必须有这一步：定妆图只有一个角度，**给模型一张正面头像却要求它转身，它必须自己发明没见过的半边脸——那正是漂移出现的地方。**

四视图提示词骨架：

```
参考图：这是角色定妆图。以这张图里的角色为准，五官、脸型、发色与发型、
        服装结构与配色、配饰位置全部保持不变。

用同一个角色生成一张四视图设定表：16:9 横版，横向均分四格，
从左到右为正面全身、四分之三侧全身、正侧全身、背面全身。
四格等高、间距均匀、站姿一致（双脚与肩同宽、双臂自然垂放），
完整入镜不裁切；纯浅灰渐变背景，无道具、无环境元素；
均匀柔光便于看清结构，但保持参考图的整体色调与渲染风格。

一致性：四个视角必须是同一个人，识别锚点（痣 / 疤 / 不对称的位置）
        在每个视角里完全一致。

负面：四个视角不是同一个人、五官漂移、发色变化、服装结构错乱、
      配饰丢失、识别特征消失、裁切出画、多余人物、塑料感、水印、文字
```

**第三步：正片阶段，用一行锚定句，不要重写整段角色描述。**
每张镜头都重写两百字角色描述，等于每张都在重新抽卡，一致性必然掉。正确做法是把角色压成**一行 60 字左右的锚定句**，每集复制不改，只改场景和动作：

```
25 岁女剑修，鹅蛋脸偏长、单眼皮细长眼、瞳色深褐，
右眼下 2mm 泪痣、左眉尾浅旧痕；
黑发低束成髻，素白长袍配灰青布带，长剑背左后。
```

喂给 Seedance 2.5 时，**定妆图和四视图两张一起当角色参考**：一张管气质与脸，一张管结构与比例。

### 两个必须知道的限制

- **参考图固定的是身份，不是行为。** 参考强度调高，角色锁得死但不再听提示词；调低，提示词生效但脸会松。每张图的平衡点都要自己找。
- **如果某一格总崩**（比如背面服装结构乱），说明**第一张定妆图里服装结构本身没说死**。回去补定妆图，别在四视图上反复抽卡。

## 七、出口前还有三件事（合规与质感）

1. **别用市面上流传的通用模板。** 那些「爆款脸提示词」被几百个团队在用，撞脸风险最高。本库每张脸都带独有的识别锚点，是给「一人一剧」用的，不是给「套模板」用的。
2. **平台在查跨剧撞脸。** 红果短剧已上线 AI 人脸相似度比对，据行业解读**跨剧角色面部相似度超 65% 会被直接驳回**；抖音有预检工具；微博对同质化 AI 内容扣减广告分成。**好消息**：原创锁定的独家角色资产，多季连载不受限——平台打压的是「一套脸演百部剧」，不是「一部剧里脸一直不变」。**要做的是每个角色一张新脸，而不是每集换一张脸。**
3. **留一点不完美。** 这一条比前面所有技巧都重要。AI 脸让人不适不是因为丑，是因为太标准了，标准到大脑的防伪机制会报警。自然的毛孔、轻微肤色不均、一道淡细纹、一颗位置精确的痣——这些「不完美」恰恰是「活人感」的藏身处。**算法能在一秒内生成一张完美的面孔，生成不出一个眼神里的半秒迟疑。**
