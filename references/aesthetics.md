# ima《AI美人指南》PPT 深度拆解（面部硬知识底座）

> 来源：用户 ima 知识库「AI技巧」中的《AI美人指南》PPT 全文 + B站 8 期公开课逐字稿。按 PPT 逻辑逐层提炼为**可复用规则**，文末附出图检查清单。
> 心法：所有五官细节都用「体积」理解、靠后期（PS / 重绘）微调——AI 直出细节仍需补。

## 0. 肌肉与肩颈（上半身气质密码，PPT「肌肉」章 + B站 ep2）

- **肩颈是上半身的「基座」**：胸锁乳突肌（耳后延伸到锁骨）与斜方肌决定气质。
- 斜方肌**必须有体积感**（不能画平），男生尤其要「立起来」才好看；远侧肩膀弧度比近侧更顺滑。
- **肩颈线条决定角色气质**：
  - 温柔纤细 → 斜方肌柔和；
  - 古风 → 微圆肩、内敛；
  - 少年感 → 宽而不壮；
  - 威武男 → 肌肉全立起。
- 女生脖子直、细、顺滑、无喉结；男生喉结在脖子约 1/2 处凸起。
- **手臂 = 热狗形**：上臂是三角肌 + 肱二/三头夹「香肠」，小臂主块（打网球者更发达）。
- 男女差异：男生多为块状肌肉，女生多为线条；女生下肢力量约为男生 7–8 成，故练下肢收益高于上肢。

## 1. 人体比例与体块（形与体）

- **比例口诀「站七坐五蹲三（个半）」**：站姿 7–7.5 头身，坐姿 5–5.5 头身，蹲姿 3–4 头身。
- **拉长逻辑**：网感/二次元图可拉到**九头身**（被接受）；**超过九头身显怪**。
- **男女差异**：男约 7.5 头、女约 7 头；腰线下 3.5–4 头 + 上 4–5 头 = 合理九头身。肩宽夸张到 **2.5–3 头**可接受，**4 头**离谱。
- **两个介入节点**：① 出图时比例不对就放弃；② 保留后用 PS 拉伸/缩短。
- **体 = 空间意识**：把人理解为有体积的方块（头/胸腔/盆腔/四肢）。上臂≈下臂、大腿≈小腿。
- **透视铁律**：近大远小、近宽远窄。

## 2. 头骨与三庭五眼（头）

- **头要圆润饱满**，易忽略**后脑勺（枕骨凹点）**= 头圆转折点，连到脖子。
- **头骨三段**：颅骨 / 面骨 / 下颌，比例因人而异。
- **三庭五眼（必背）**：发际→眉→鼻底→下巴三等分；以一只眼长为单位，脸宽五等分。
- **眼睛位置**：头部约 1/2 处；幼态审美会缩短下庭、整脸变短。
- **额头「饱满」≠发面馒头**：指轮廓饱满，要有明暗对比（中亮-灰-暗），并做出**额结节拐点 + 额沟**两个点（磨皮太干净会丢）。
- **眉弓**：韩系下压、欧美立体；饱满眉弓**降低眼凸度、显精神**；眉分三段（头/身/尾）。

## 3. 眼睛（眼）

- **眼形 = 平行四边形 / 上三下二**，非对称两个半圆。
- **眼白是球体**：靠内更深、中间最亮、外侧偏暗；忽略则无神。
- **侧脸眼形变最难**：正圆→椭圆→侧面成线（零形）。45° 微侧眼必是**平三角形**（非完整四边形）。
- **眼距近大远小**：侧脸内眼距缩小。
- **眶周折叠度（眼窝深浅）= 骨相关键**：深则深邃精神，浅则疲惫无神——比眼形更决定「美人感」。
- **鼻额角**：鼻根与瞳孔连线自然（太高=阿凡达脸）；**鼻唇角 90–100°** 理想。

## 4. 鼻子和嘴唇（鼻与唇）

- 鼻是脸部正中心、确定脸的角度；含鼻根/梁/头/翼/中隔，是体积体。
- 正面鼻底偏暗找转折；鼻头球体高点打亮；鼻孔点状（**正面露一点更好**）。
- **双 C 线**（眼中外侧两条线）让脸饱满；**海鸥线**（鼻头比鼻翼低一点像海鸥）更美。
- **鼻基底 = 地基**：低则中面部凹陷/嘴凸；侧脸鼻基底要饱满圆润立体（「高鼻梁」指这里）。
- 唇 = 体积：上圆下两圆的结构（唇珠圆、两侧唇颊）。**颏唇沟 120–130°** 理想，太浅显凸嘴。

## 5. 侧脸骨相（面部折叠度）

- **下巴非倒三角**，有弧度流畅度即可；模特可凹凸有致（颧骨高+尖下巴），别离谱。
- **E 线（鼻-唇-下巴三点一线）= 审美平面**：直面唇在線内、凸面微超、凹面内缩；仅参考非绝对。
- **下颌角**：偏低脸偏方、端庄成熟；偏高（上提）更甜美清秀。
- **颏颈角**（下巴-脖子）约 **120°** 为宜，太大显土；侧脸打阴影体现下颌线。
- **面部折叠度 = 所有脸部角度总和**：高折叠度 = 颧骨微露不凸、鼻挺、眉骨立体、苹果肌上扬、下颌线分明、脸小又立体。麦橘认为这比「桃花眼/柳叶眼」更本质。
- **四角精致的阈值**：鼻额角 / 鼻唇角 / 颏唇沟 / 颏颈角做到 **100 多度**才精致。

## 5.5 颧颌夹角（PPT「颧颌夹角」章）

- 颧骨凸点垂线与下颌角水平线相交形成的角度；**角度越大，中下面部越收紧、趋瓜子脸**；角度小或负角趋圆脸/方脸。
- 但非越大越好：颧骨靠外且突度大者，颧弓夹角过大易显面颊瘦削、影响脸型流畅度。

## 5.6 阔面脸 vs 窄面脸（PPT「阔面脸/窄面脸」章 + B站 ep7）

- **阔面脸**：脸型线条偏硬朗，颧骨高外扩，下颌宽大，棱角感明显、高冷距离感；折叠度低，五官量感相对小、留白多。
  - 不喜欢的留白是「大而无当」；好看的留白位置比例恰到好处：开阔额头、舒展眼眶外侧、平整微阔面中、稳重不粗放下颌，支起大气有分量框架。
- **窄面脸**：纤细骨骼 + 较高折叠度，面部更尖锐、重心靠上；额骨下颌骨骼感弱但集中内收，侧面立体、正面细腻层次。
  - 重心过靠上会「头重脚轻」；太阳穴饱满度很重要以平衡骨骼，遵循「上窄下宽」；一定长度下巴增加纵向稳定感、减缓尖锐感。

## 6. 面部美学（妆容与风格）

- **面部平整度**：线条平滑紧致；皮相凹陷尽量避免。
- **凹陷美学（拒「馒化」）**：骨相应有折叠角度，皮相尽量无深凹但要有**适度高级凹陷**；全填平=发面馒头，要避免。
- **骨相美**（耐看、高级脸）vs **皮相美**（第一眼好看不耐看）。
- **妆容重心四选二**：腮红 / 唇妆 / 眉毛 / 眼妆。氛围感重腮红+唇；冲击力重眉+唇。
- **浓颜系**：五官占比大、眼大、色浓（发/瞳/唇都浓），常与混血感相关。**淡颜系**：清秀协调、脸裸白多。
