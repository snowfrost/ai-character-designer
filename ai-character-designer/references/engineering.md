# 工程化流程（刺猬星球 / 公开角色设计教程）

> 来源：公开版《AI角色设计保姆级教程：从一张脸到完整人物设定》《AI角色总"换脸"?3招锁定固定形象》。刺猬星球知识星球内付费文章如有具体链接可贴入做精确 ingestion。

## 1. 第一步：先做「标准照」（角色身份证）

大多数人一开 AI 就想搞大场面（战斗/霓虹/电影感），这类图对角色识别不友好——信息太多，模型混淆重点。正确起点是**一张无干扰的标准角色图**：

- 背景干净（白/浅灰）、无场景元素、无复杂构图、无情绪化光影、角度正面、光线均匀。
- 核心不是审美，是**信息稳定**——让模型只记「这个人长什么样」。

## 2. 第二步：三步走，从「脸」到「人」到「资产」

1. **锁脸（最关键）**：只做面部特写，不断生成/筛选/调整，直到出现一张可固定的脸（五官结构稳定、轮廓清晰、有记忆点、不依赖光影加成）。这张图是后续所有图的**锚点**。
   - 为什么：全身图里脸的信息权重太低，模型优先保证整体合理而非脸一致 → 脸漂移。
2. **做全身，但贴着脸走**：明确身高比例、体型、肩宽姿态、基础穿搭；提示词强化「保持面部特征与参考图完全一致」。脸是核心资产，其它是附属变量。
3. **四视图，让角色变成可调用资产**：正面+侧面+背面+面部超特写放一张图。解决「远看还行、镜头推近脸变形」——补齐模型的**多角度认知**，之后生成八百个角度都不会换人。

## 3. 第三步：为什么变平均 → 拆结构写差异

不要写「漂亮的女孩」，要拆：**脸型**（偏圆/偏方）、**眉眼**（上挑/下垂）、**鼻子**（鼻梁高低+鼻翼宽窄）、**嘴唇**（厚薄+唇峰）、**皮肤**（冷白/小麦/雀斑）、**发型**（长度+形状+层次）。**重点不是写「美」，是写「差异」**。

## 4. 衣服：拆四层，别复制

配色逻辑（组合方式）／廓形结构（修身/宽松/落肩）／材质质感（挺括/柔软/垂坠）／设计类型（领型/袖型/口袋）。要的是「这件衣服为什么合适」的感觉，翻译成语言才是正确输入。

## 5. 后期锁死角色（身份锁）

换衣服/场景/状态时，提示词必须含两部分：**要改什么 + 不能改什么**，重点永远在后者。

- 不能改：面部五官、脸型结构、身材比例、发型发色；
- 只允许改：衣服、配饰、场景元素。

本质：给角色建立「身份锁」，锁住核心才能自由变表层。

## 6. 一致性三招（视频/连续图适用）

1. **三视图定妆照**：写实风、摄影棚、正/侧/背三视图、白底无阴影；满意角色存入工具「角色库」并打唯一标签（如 `#主角_李明`）。
2. **剧本结构化拆解**：每个分镜强制带角色标签，明确调用对象。
   - ❌「一个人走进房间」 → ✅ `#主角_李明 走进昏暗的房间`
   - 表情语法：`【角色名】(表情状态) 动作 + 场景`，如 `【云舒】(微笑)在庭院散步`。
3. **画布导演（无限画布）**：拖分镜入时间轴，用「画面约束」上传场景参考图，AI 同时读角色 ID + 场景参考；崩脸时**只微调该节点约束（如加面部特写权重）重生成该片段**，不重做全片。

## 7. 可复用提示词模板（原文，做「全身 / 四视图」锚点图时直接用）

- **全身图**：
  > 需要基于给定的面部参考图，制作一张人物的正面全身形象设计图。请务必保证生成的人物在脸型、五官比例、发型发色等面部特征上与参考图完全一致，维持原有的人物辨识度。画面要求人物以正面站姿完整呈现，从头到脚清晰可见，能够准确展示其身材比例以及所穿的服装和鞋子。拍摄视角为平视，光线采用均匀的平光照明，确保没有明显的阴影遮挡。背景请使用干净的纯色，不要添加任何多余的干扰元素。

- **四视图**：
  > 请生成一张16:9比例的角色设定图。画面布局要求：左侧放置人物面部超大特写；右侧依次排列人物的全身正面、侧面及背面三视图。人物需从头到脚完整入镜，采用平视视角与均匀光照，背景保持纯色简约。核心要求：所有视图必须为同一角色，确保面部特征、发型、服装配饰及身材比例绝对一致，仅观察角度发生变化。整体排版需清晰规整，符合标准角色三视图规范。

## 8. 出图—修图工作流（麦橘 ep8）

1. 选工具（剧量/SD/即梦等）→ 出图时**选种/选模/选参数**；
2. 底图只打 **60–70 分**（清晰度与细节不达 90，正常）；
3. 留 **PS 空间**：蒙版、图层、滤镜、液化，微调形/角度/光影；
4. 难调的图直接扔，只留「可批（可修）」的；
5. 多看真人怎么长，训练「识别哪里奇怪」的眼力。

## 9. 撞脸 / 崩脸自救清单

- 换脸漂移 → 回锚点（标准照），全身图强制「与参考图完全一致」+ 四视图补多角度认知。
- 千人一面 → 拆结构写差异，加不完美细节（毛孔/雀斑/单眼皮/高颧骨）。
- 侧脸眼塌 → 45° 眼必为平三角；远小近大，内眼距缩小。
- 蜡像假面 → 去掉「完美皮肤/8K」类词，加肌理与血色。
- 视频崩帧 → 只重生成该节点（加面部特写权重），不重做全片。
